⚡ Circuit Breaker: The Safety Valve That Prevents Cascading Failures

System Design · Nightly Insight · June 22, 2026 (Monday)
🧒 Like you're 5

Imagine you have a toy train track. One of the train cars gets stuck and stops moving. If the other cars keep pushing, they'll all crash together and wreck the whole track!


So you put in a magic gate that watches the stuck car. When it sees trouble, it opens and says "Stop! Nobody go down that track until it's fixed!" After a while, it lets one car try — if it goes through, it lets everyone go again. If it's still stuck, the gate stays open.


That magic gate is a circuit breaker. It protects the whole system by stopping traffic to a broken part before everything breaks.

🔄 The Three States

CLOSED
Normal operation
→
OPEN
Failing fast
→
HALF-OPEN
Testing recovery
↺

📊 State Transitions

CLOSED → OPEN
Error rate exceeds threshold (e.g., 50% of last 20 requests)
OPEN → HALF-OPEN
After timeout period (e.g., 30s), allow one probe request
HALF-OPEN → CLOSED
Probe request succeeds; reset the circuit
HALF-OPEN → OPEN
Probe fails; go back to open state, reset timer

🛠️ Python Implementation (sliding window)

from enum import Enum
from collections import deque
import time

class State(Enum):
    CLOSED = "closed"
    OPEN = "open"
    HALF_OPEN = "half_open"

class CircuitBreaker:
    def __init__(self, failure_threshold=5, 
                 recovery_timeout=30, 
                 window_size=20):
        self.state = State.CLOSED
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.window_size = window_size
        self.requests = deque(maxlen=window_size)
        self.opened_at = None

    def call(self, func, *args, **kwargs):
        if self.state == State.OPEN:
            if time.time() - self.opened_at > self.recovery_timeout:
                self.state = State.HALF_OPEN
            else:
                raise Exception("Circuit OPEN — failing fast")

        try:
            result = func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise

    def _on_failure(self):
        self.requests.append(False)
        if self._failure_rate() >= 0.5 and \
           len(self.requests) >= self.window_size:
            self.state = State.OPEN
            self.opened_at = time.time()

    def _on_success(self):
        self.requests.append(True)
        if self.state == State.Half_OPEN:
            self.state = State.CLOSED
            self.requests.clear()

    def _failure_rate(self):
        if not self.requests:
            return 0.0
        return (len(self.requests) - sum(self.requests)) / len(self.requests)

kind: DestinationRule
metadata:
  name: inference-pool-cb
spec:
  host: inference-pool
  trafficPolicy:
    connectionPool:
      tcp:
        maxConnections: 100
      http:
        h2UpgradePolicy: DEFAULT
        http1MaxPendingRequests: 100
        http2MaxRequests: 1000
    outlierDetection:
      consecutive5xxErrors: 5
      interval: 30s
      baseEjectionTime: 30s
      maxEjectionPercent: 50

⚙️ Key Tuning Parameters

Failure Threshold
Too low → false positives
Too high → slow detection
Recovery Timeout
Too short → retry too early
Too long → stale fallback
Window Size
Sliding window gives better signal than fixed counters
Fallback Strategy
Return cached data, degraded response, or queue for retry

🔗 Complementary Patterns

Retry + Backoff
Retry on transient errors BEFORE circuit opens
Bulkhead
Isolate pools per dependency — limits blast radius
Rate Limiting
Prevent the overload that triggers circuit in the first place
Health Endpoint
Let the circuit breaker probe /health instead of /api
⚡ Micro-action (5 minutes)

Pick one downstream service your NVCF inference pipeline depends on. Check: does it have a circuit breaker configured (outlier detection, connection pool limits in Istio/Envoy)? If not, add a DestinationRule with consecutive5xxErrors: 5 and baseEjectionTime: 30s. One kubectl apply and you've just halved your cascade risk.
