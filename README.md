# 🏗️ System Design

Daily insight cards on system design, distributed systems, and architecture patterns.

## Structure

| Folder | Description |
|--------|-------------|
| databases/relational/ | PostgreSQL, MySQL, sharding, replication |
| databases/nosql/ | Redis, MongoDB, Cassandra, DynamoDB |
| caching/ | Cache strategies, CDN, write-through, write-behind |
| load-balancing/ | Algorithms, DNS, reverse proxy, global LB |
| messaging/ | Kafka, RabbitMQ, SQS, event-driven architectures |
| microservices/ | Service mesh, API gateway, saga, CQRS |
| consistency-models/ | CAP, PACELC, CRDTs, consensus algorithms |
| api-design/ | REST, GraphQL, gRPC, WebSocket, versioning |
| distributed-computing/ | MapReduce, Spark, stream processing |
| security/ | Auth (OAuth, JWT), encryption, DDoS mitigation |

## Cards

Each nightly insight generates a standalone HTML card in the relevant folder.
