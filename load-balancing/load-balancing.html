⚖️ Load Balancing Algorithms

System Design · How requests get distributed across servers

🔄 Round Robin

Requests go to each server in turn: A→B→C→A→B→C. Simple, but no awareness of server load.
SimpleNo load awareness

🎯 Least Connections

Send to the server with fewest active connections. Adapts to varying workload durations.
AdaptiveGood for long-lived connections

⏱️ Least Response Time

Route to the fastest recent responder. Picks least busy AND fastest server.
FastestNeeds monitoring

🧮 IP Hash

Hash client IP → same client hits same server. Session affinity without sticky cookies.
Sticky sessionsUneven if IPs cluster
